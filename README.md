A modern, fast, and completely free mobile application to convert images from your gallery or camera into PDF documents. Inspired by CamScanner, but **with no ads, no watermarks, and no subscriptions**.

Built with **React Native** and **Expo Go**.

---

## ✨ Features

- 📸 **Capture & Multiple Import**: Select multiple photos from your gallery or take pictures directly with the camera.
- 🎨 **CamScanner-Style Filters**:
  - Magic Color (Document Enhancement)
  - Grayscale
  - High Contrast B/W
  - Original Mode
- 🔄 **Organization & Editing**:
  - Easily reorder pages (move up / down).
  - Native 90° rotation.
  - Add or delete pages on the fly.
- ⚙️ **PDF Configuration**:
  - Page Formats: A4, Letter, Legal.
  - Orientation: Portrait or Landscape.
  - Customizable margins (No margin, Small, Medium, Large).
- 📤 **Save & Share**:
  - Local storage saving with a recent documents history.
  - Direct sharing via WhatsApp, Email, Drive, or native system storage.

---

## 🛠️ Technologies

- **Expo SDK 57** (100% compatible with the latest **Expo Go** version)
- **React Native** + **TypeScript**
- **expo-image-picker** & **expo-image-manipulator**
- **expo-print** & **expo-file-system** & **expo-sharing**
- **React Navigation v7**

---

## 🚀 Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/FranciscoArias10/LibrePDF.git
   cd LibrePDF
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the Expo development server:
   ```bash
   npx expo start --android
   ```

4. Scan the QR code using the **Expo Go** app on your Android or iOS device.

Una aplicación móvil moderna, rápida, libre y 100% gratuita para convertir imágenes de la galería o fotos de la cámara a PDF. Inspirada en CamScanner, **sin anuncios, sin marcas de agua y sin suscripciones**.

Desarrollada con **React Native** y **Expo Go**.

---

## ✨ Características

- 📸 **Captura e Importación Múltiple**: Selecciona varias fotos de la galería o toma imágenes con la cámara.
- 🎨 **Filtros Estilo CamScanner**:
  - Magic Color (Mejora de Documento)
  - Escala de Grises
  - Alto Contraste B/N
  - Modo Original
- 🔄 **Organización y Edición**:
  - Reordena páginas fácilmente (subir / bajar).
  - Rotación nativa en 90°.
  - Elimina o agrega páginas de forma instantánea.
- ⚙️ **Configuración de PDF**:
  - Formatos de página: A4, Carta (Letter), Oficio (Legal).
  - Orientación: Vertical o Horizontal.
  - Márgenes personalizables (Sin margen, Pequeño, Mediano, Grande).
- 📤 **Compartir y Guardar**:
  - Guardado en almacenamiento local con historial de documentos.
  - Compartir directo por WhatsApp, Email, Drive o almacenamiento nativo del sistema.
