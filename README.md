Una aplicación móvil moderna, rápida, libre y 100% gratuita para convertir imágenes de la galería o fotos de la cámara a PDF. Inspirada en CamScanner, **sin anuncios, sin marcas de agua y sin suscripciones**.

Desarrollada con **React Native** y **Expo Go**.

---

## ✨ Características

- 📸 **Captura e Importación Múltiple**: Selecciona varias fotos de la galería o toma imágenes con la cámara.
- 🎨 **Filtros Estilo CamScanner**:
  - Magic Color (Mejora de Documento)
  - Escala de Grises
  - Alto Contraste B/N
  - Modo Original
- 🔄 **Organización y Edición**:
  - Reordena páginas fácilmente (subir / bajar).
  - Rotación nativa en 90°.
  - Elimina o agrega páginas.
- ⚙️ **Configuración de PDF**:
  - Formatos de página: A4, Carta (Letter), Oficio (Legal).
  - Orientación: Vertical o Horizontal.
  - Márgenes personalizables (Sin margen, Pequeño, Mediano, Grande).
- 📤 **Compartir y Guardar**:
  - Guardado en almacenamiento local con historial de documentos.
  - Compartir directo por WhatsApp, Email, Drive o almacenamiento nativo.

## 🛠️ Tecnologías

- **Expo SDK 52** (Compatible 100% con **Expo Go**)
- **React Native** + **TypeScript**
- **expo-image-picker** & **expo-image-manipulator**
- **expo-print** & **expo-file-system** & **expo-sharing**
- **React Navigation v7**

## 🚀 Instalación y Uso

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/FranciscoArias10/LibrePDF.git
   cd LibrePDF
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo de Expo:
   ```bash
   npx expo start --android
   ```

4. Escanea el código QR desde la app **Expo Go** en tu dispositivo Android.
